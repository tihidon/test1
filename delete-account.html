Delete Snail City game data

Developer: T.D Studio. Contact: tdstudio.games@gmail.com.

Delete local progress

Open the game, go to Settings (Podešavanja), then select Delete local data (Obriši lokalne podatke). Confirm the operation. This changes data on the current device only.

Delete an optional cloud save copy

Open Settings → Cloud copy. If your anonymous cloud session is still active, select Delete only cloud copy (Obriši samo cloud kopiju) and confirm. This removes the associated cloud-save row, not the local save or anonymous authentication account.

Delete the cloud account itself

The test version does not provide self-service removal of the anonymous Supabase Auth account. To request full deletion of your account and associated data, email tdstudio.games@gmail.com with the subject “Snail City data deletion”. We may need to verify account ownership; do not send your password or session tokens.
