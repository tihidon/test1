# CSS, DOM, functions
Read [SC-CODE-01](standards/standardi/SC-CODE-01-CSS-DOM-FUNKCIJE.md) and [SC-RAD-01](standards/standardi/SC-RAD-01-POSTAVKA-IZMENA-BRISANJE.md). Enforce adopted C/D/J rules and actual baseline ratchet. One existing style owner, preserve cascade context, selector specificity and fallbacks. No automatic merging/reordering. Existing tokens, scoped DOM, native controls, delegation, SR/EN, focus and reduced motion. Context-sensitive safe sinks; no raw user HTML. New function thresholds are project rules; no meaningless wrappers or silent exceptions. Error, cancellation and cleanup at responsible boundary. WCAG 2.2 AA target; actual tests required.
