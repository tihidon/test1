Snail City — Privacy Policy

Updated: November 22, 2026. Developer: T.D Studio. Contact: tdstudio.games@gmail.com.

Game data

Game progress (including creatures, resources, levels, buildings, timers and other gameplay state) is saved locally on your device using browser storage. Performance and gameplay analytics shown inside the game are kept on your device; they are not part of the optional cloud backup.

Optional cloud backup

Cloud backup is optional and is enabled only when you choose to connect it. Supabase provides anonymous authentication and database storage. An anonymous account has a technical identifier. When you explicitly choose Save cloud copy, the app uploads your existing game-save JSON to a database row associated with that account. No email address is required by this option. Cloud restore presents a preview and requires your confirmation before replacing local progress. Connection and service logs may contain standard technical information such as IP address used to deliver the service.

An anonymous account is scoped to the browser session. Clearing browser storage or switching device may make the cloud copy inaccessible unless you have an appropriate future account-linking option. Export a copy of your progress separately. Only a publishable API key is embedded in the game; row-level access rules limit access by account identity.

Legacy import

If you choose to import progress from the older Snail City version, the app may read the saved game from the older Supabase project if a valid legacy session is still available on the same website. Import is optional and uses a confirmation screen.

Service providers

Supabase provides optional authentication and cloud database services. Netlify may host the web app. Providers may process necessary connection and security logs according to their policies.

Retention and deletion

In the game, you can separately delete local game data and, if connected, delete your cloud save copy. Deleting the cloud save row does not delete the anonymous authentication record; signing out also does not delete it. To request full removal of your cloud account or assistance with inaccessible data, contact tdstudio.games@gmail.com. We may need information to verify your request. Do not send passwords or private access tokens by email. See Data deletion steps.

Security, children and changes

We use authenticated account checks and database row-level security for cloud saves. No internet service is risk-free. Store availability and child-audience settings are not finalized in this test build. This policy will be updated if advertising, paid purchases or other data practices are introduced.
