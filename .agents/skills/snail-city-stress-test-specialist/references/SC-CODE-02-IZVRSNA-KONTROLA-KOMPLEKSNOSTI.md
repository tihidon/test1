# SC-CODE-02 — izvršna kontrola kompleksnosti (kandidat)

Dodatak SC-CODE-01, SC-LOOP-01, SC-PL-01 i SC-DEC-01. Nema novog vlasnika koda. Baseline eddfa33acf5f875f2dbdf746ebf436651e61f80b. Svi pragovi iz SC-CODE-01 ostaju, bez automatskog brisanja ili masovne podele funkcija.

## CSS/JS ratchet
Originalni tools/sc-code-01 (5 fajlova) prenet iz tihidon/snail-city-test@12f986c, bez izmene originalnih baseline vrednosti. Koristi postojeće tinycss2==1.5.1, Acorn 8.19.0 i acorn-walk 8.3.5, samo u dev venv/privremenom node direktorijumu. `python tools/sc-code-01/quality_gate.py --base <full reviewed commit> --out <new report.json>` meri svih 18 kanonskih metrika na baseline i kandidatu; dodatno izveštava lokacije identičnih selektora po kontekstu, velike vrednosti bez sadržaja resursa, top 20 pravila po deklaracijama, CSS parse greške i neobrađene at-rules. Originalni alat ima ograničenja: regex deljenje selektora i vrednosti nije potpuna CSS semantika; dodatne lokacije koriste tinycss2 tokene. Ne tretirati fallback deklaraciju kao sigurno nepotrebnu. CSS bytes nisu kriterijum baga; velike Base64 vrednosti odvojiti od strukture.

PR CI koristi stvarni base SHA; manual CI koristi zamrznuti početni commit eddfa33acf5f875f2dbdf746ebf436651e61f80b. Prethodni P1 baseline se ne menja. Ako istorijski baseline ne prolazi, tooling-only identičan HTML može imati PASS_NO_GROWTH uz eksplicitni historical_status FAIL; runtime HTML izmena ne prolazi dok istorijski gate nije razrešen. Brojčani ratchet nije dokaz C01–C12/D01–D10/J01–J10 u celini. Za pojedinačne nove funkcije proveriti limite i vlasništvo čak ako zbir nije porastao; ne skrivati novu grešku smanjenjem druge metrike. Canonical SC-CODE-01 §8 ostaje nadređen.

## Petlje i runtime
Proširen postojeći audit_loops.cjs: sve for/while/do petlje dobijaju lokaciju, owner, uslov (skraćen), nesting i operacije schedulera/geometrije/DOM poziva unutar iste funkcije. Heuristika ne dokazuje terminaciju, alias, callback ili cross-block call graph. Dokaz zahteva prvo odstupanje, realne pozivaoce i runtime reprodukciju. Novi Chromium fixture testovi: legitimna bounded while i RAF cleanup, namerno dupli RAF koji pada iz tačnog razloga, stvarni JS hang prekinut spoljnim watchdogom i dupli DOM ID. Fixture nije dokaz da igra ima ili nema te bagove. Realni game smoke dodatno beleži DOM broj/dubinu/decu, duple ID, broj style blokova i linkova online, posle scenario assertiona i offline; nalazi su review-only za nasleđeni shell. D05/D09 za nove ekrane proveriti zasebnim stvarnim scenarijem. DOM probe ne čita geometriju, nije FPS test. Funkcionalni scenariji, RAF/timer/listener resursi na stvarnoj igri i fizički Android i dalje zasebni QA.

## Gate i artefakti
CI: originalni metric parser i nove fixture provere, AST JSON, quality JSON, browser fixture i DOM snapshot u report.json. Ništa se ne ubacuje u proizvodni JS/CSS. Izvršni rezultati kandidata tek po CI; nema tvrdnje o stvarnom agent eval. SC-DEC-01: blokiraj novu regresiju, lokaciju analiziraj, ne briši validan kod radi broja.
