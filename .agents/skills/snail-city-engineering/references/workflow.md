# Workflow
Read [SC-AGENT-01](standards/standardi/SC-AGENT-01-OBAVEZNI-STANDARD-AGENATA.md), [SC-RAD-01](standards/standardi/SC-RAD-01-POSTAVKA-IZMENA-BRISANJE.md), [SC-FUNC-01](standards/standardi/SC-FUNC-01-REGISTAR-FUNKCIJA-I-POZIVA.md), [three deletion checks](standards/standardi/SC-BRISANJE-3-PROVERE.md). Preflight git status, target SHA, publish identity, acceptance, scope and rollback. Find existing owner and full call path. Function card: owner/symbol, contract/units/error, reads/writes, callers/dependencies, lifecycle and tests. Target unique anchors, preserve unrelated bytes and working changes, no whole-file regeneration. Update existing index through SC-F08 generator, not manual IDs. Deletion requires static+runtime+regression/visual checks. Zero callers does not prove dead code. Keep unresolved dynamic references and old save readers as needed. Feature removal requires approval.
