# QA and release
Read [SC-AGENT-01 G0–G7](standards/standardi/SC-AGENT-01-OBAVEZNI-STANDARD-AGENATA.md), [PW-01](standards/pwa-offline/PW-01-STANJE-0.8.92.md). Relevant gates include identity, static, functional, visual, persistence/offline, performance, physical device and approval. No required gate waived. Save backup/recovery, migration, duplicate commands, reload, IDB error/abort, offline cold restart, SW upgrade/rollback in isolated test profile. Never clear player storage. Verify assets, manifest, MIME, published bytes and worker scope. Actual Chromium screenshots, real-frame motion evidence, separate physical Android evidence. Report PASS/FAIL/BLOCKED/NOT RUN with actual commands and environment. No unapproved release.
