# Architecture investigation and acceptance
1. Trace the user action through the real handler, dynamic dispatch, state writer, persistence and first visible frame. Record unknown call edges, source anchor and build identity. Freeze expected behavior with QA before editing.
2. Before moving JS identify top-level side effects, captured globals, module order and public names. Use tools/build.py in two clean worktrees and compare hashes to the publish root. Check actual UI behavior before and after module extraction.
3. Capture CSS cascade, dynamic selectors, lazy screens and focus. Use per-screen coverage and inspect forced layout events. For duplicate functions compare literals, async boundaries, property access and side effects before merging. Review changed functions independently of aggregate size.
4. Track GPU resource ownership, context generation, creation, deletion and recreation. Verify repeated scene teardown and context loss/restoration. Check legitimate texture refresh after source updates.
5. Test SW activation, controller, response identity, cache migration, interrupted writes, duplicate settlement and save recovery using sanitized persistent profiles. Rollback must preserve a newer save.
6. Validate Supabase changes on isolated data using two test identities, expected RLS grants and denials, migration compatibility and replay of idempotent commands. Keep privileged keys outside the client.
7. Evaluate ESLint on an isolated pinned developer installation. Compare new findings by rule and location to the reviewed baseline, independently of aggregate changes. Use AST similarity and CSS coverage as candidates for manual review. Preserve legacy thresholds.
8. Separate static quality, functional, diagnostic and reliability CI runs. Retain failed attempts and environment identity. Verify upstream action revisions and runner compatibility before updates. Validate detectors with intentional faults and valid controls. For a timing regression compare baseline, candidate and rollback under PL-01, separately from instrumented runs.
9. Deliver the smallest owner-level change, raw results, unresolved contradictions and rollback point. An independent reviewer inspects the original evidence.
